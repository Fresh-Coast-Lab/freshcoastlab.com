      How I work

      Five rules I actually follow.

      1. Verify, don’t assume.If a command can prove it, I run the command. Reasoning that only suggests something is true isn’t done.
      2. A human approves.Agents draft. I decide. Nothing in my house or on this site ships without a yes.
      3. Monitor agreement, not uptime.Healthy-looking systems fail quietly. I watch for two signals that should agree and don’t.
      4. Build it before you advise on it.I don’t recommend AI I haven’t run myself. The learning is in the doing.
      5. Explain it so anyone can use it.If the person who owns it can’t explain it back to me, I’m not finished.
