April 6, 2026Building

Start by building something for yourself.

I built my own AI channel strategist. The learning was in the doing.

I wrote the first version of this from a dentist's chair, remotely checking in on an AI agent I'd built over a few weeks of late nights.

It knows my voice, my audience and what's happening in cybersecurity this week. It drafts presentations, writes talk tracks that actually sound like me, and briefs me on MSP news every morning. No off-the-shelf tool. Just Python, the Claude API, and a lot of trial and error.

Why build it yourself

MSPs ask me the same question at almost every event: where do we start with AI? My answer is always the same. Start by building something for yourself.

Not a product. Not a pilot for a client. Something that solves your own annoying problem. You'll learn more in two weekends of building than in two months of webinars, because you'll hit the real problems: where the model is confidently wrong, what it should never be allowed to touch, and how much context it actually needs to be useful.

What it taught me

The model is the easy part. The hard part is memory, guardrails and knowing when it's quietly failing. That's why everything I run now shares one memory across machines, gets scanned for secrets before it's saved, and gets checked by something other than itself. This whole site was built the same way, with Claude Code doing the heavy lifting and me approving every change.

You can't advise customers on AI you've never built with. Go build something.
